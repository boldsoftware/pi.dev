This is an open source code dump of the podcast generator at https://pi.dev, launched in Dec 2024.

It was a side project for us, and it has not been maintained in six months. Sadly, the time has come to let it go.

This code is being open-sourced in response to community interest, with its git history scrubbed (sorry). It probably won't be easy to run as-is. Hopefully someone will steal the interesting bits (or have an agent steal the interesting bits) and run with it.
